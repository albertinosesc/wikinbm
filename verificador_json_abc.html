🔢 Verificador de Numeração e Ordenador

Cole um JSON com lista de objetos (cada um com campo titulo no formato "Número - Nome"). O sistema extrairá os números, ordenará e dirá quais estão faltando.

📖 Tutorial – Como usar

1. Cole o JSON – deve ser um array de objetos. Cada objeto deve ter pelo menos um campo titulo no formato "Número - Nome".

2. Clique em "Ordenar e Verificar" – o sistema irá:

  • 🔢 Extrair o número do início de cada título.
  • 📊 Ordenar a lista do menor para o maior número.
  • 🔎 Identificar quais números estão faltando no intervalo entre o menor e o maior.
  • 📝 Exibir a lista ordenada (em linha única) e os números faltantes.

3. Baixar ou copiar – use os botões para:

  • Baixar JSON – salva o array ordenado em formato compacto (uma linha).
  • Copiar JSON – copia o JSON compacto para a área de transferência.
  • Baixar Faltantes – salva em um arquivo .txt a lista de números que faltam (um por linha).

Exemplo:

Entrada: 23933, 23931 → Ordenado: 23931, 23933 → Faltando: 23932
