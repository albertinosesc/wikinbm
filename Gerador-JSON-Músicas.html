🎵 Gerador de JSON para Músicas

📖 Tutorial – Como usar

1. Preencha a categoria – ex: Internacional, MPB, Rock.

2. Cole os títulos – cada linha deve seguir o formato:

Número - Nome da Música - Compositor

Exemplos:

  • 181 - Master Crowley's - Ireland
  • 23931 - A Casa - Vinícius de Moraes
  • 23933 - Bete Balanço - Cazuza

3. Clique em "Gerar JSON" – o resultado aparecerá abaixo.

4. Use os botões para copiar ou baixar o JSON.

Formato do JSON gerado:

  • titulo – número + nome da música (ex: "181 - Master Crowley's")
  • compositor – o terceiro campo (ex: "Ireland")
  • categoria – a categoria que você digitou
  • path – caminho no formato musicas/categoria/numero.abc

O JSON é gerado com cada objeto em uma linha, facilitando a leitura e o processamento.
