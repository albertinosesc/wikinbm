📖 Tutorial – Processador em Lote de ABC → JSON

1. Selecionar a pasta
Clique em "📁 Selecionar Pasta" e escolha a pasta que contém seus arquivos .abc. O aplicativo mostrará quantos arquivos foram encontrados.

2. Configurar as opções

  • Categoria – define o valor do campo categoria no JSON. Ex: Músicas, Folclore, Internacional.
  • Compositor (campo) – escolha de qual campo extrair o compositor (ex: C:, O:, S:, B:, Z: ou Nenhum). O aplicativo também tenta O: e S: como fallback.
  • Prefixar caminho – define o prefixo do campo path no JSON. Ex: musicas/ → "path": "musicas/101.abc".

3. Processar
Clique em "⚡ Processar Todos". O aplicativo lerá todos os arquivos, extrairá cada música (separadas por X:) e gerará um JSON com uma entrada por música. O título é limpo automaticamente para evitar duplicação (ex: "98 - 098 - Fred Finn's" → "98 - Fred Finn's").

4. Visualizar e exportar

  • O JSON gerado aparece na tela, com cada objeto em uma linha.
  • Uma tabela resumo mostra as primeiras 50 músicas.
  • Use "📋 Copiar JSON" para copiar o JSON para a área de transferência.
  • Use "💾 Baixar JSON" para salvar o arquivo acervo_completo.json.

5. Integrar com o Acervo Musical
O JSON gerado pode substituir os arquivos da pasta dados/ (ex: musicas.json) para que o musicas.html liste todas as músicas individualmente.
